# Host Application Integration Guide

This guide details how to integrate the **Embeddable Stock Research Module** into your desktop or mobile host application.

---

## 1. Overview & Integration Architecture

The module can be integrated via two primary patterns:
1. **Webview Panel Mode**: Embed a native webview container (`380px–420px` width) loading the panel URL. Communication happens via `window.postMessage`.
2. **Headless REST API Mode**: Call the module's REST API directly from your native host UI (macOS, Electron, Flutter, React Native, iOS, Android).

---

## 2. Option A: Webview Panel Handoff (Slide-In Drawer)

### 2.1 Webview URL Construction
Point your webview to the module's base URL with query parameters:
```http
http://localhost:8000/?mode=embedded&theme=dark&token=YOUR_HOST_JWT_TOKEN&ticker=AAPL
```

| Parameter | Values | Description |
|---|---|---|
| `mode` | `embedded` \| `standalone` | Set to `embedded` for chromeless `380px-420px` drawer layout. |
| `theme` | `dark` \| `light` | Set host theme mode. |
| `token` | `<JWT_STRING>` | Host application JWT token for authentication. |
| `ticker` | `AAPL`, `TSLA`, `sbi stock`, etc. | Initial stock symbol or company name. |

### 2.2 JS PostMessage Event Contract

#### 1. Events Emitted by Module to Host App
Listen to `window.addEventListener('message', ...)` in your host webview wrapper:

```javascript
window.addEventListener('message', (event) => {
  const { type, payload } = event.data;

  switch (type) {
    case 'stock-module:ready':
      console.log('Module loaded successfully:', payload.timestamp);
      break;

    case 'stock-module:close':
      console.log('User clicked close button inside module. Triggering drawer slide-out animation...');
      // Host code to hide or slide out drawer frame
      break;

    case 'stock-module:error':
      console.error('Module XHR error:', payload.statusCode, payload.error);
      break;
  }
});
```

## 3. Option B: Headless REST API Specification

All API endpoints (except `/api/health`) require the Bearer JWT token:
`Authorization: Bearer <HOST_APP_JWT_TOKEN>`

### 3.1 Health Probe (`GET /api/health`)
Checks if module service and trained model are operational.

**Response `200 OK`:**
```json
{
  "status": "ok",
  "service": "stock-research-module",
  "version": "1.0.0",
  "model_loaded": true,
  "model_path": "/app/backend/ml/model.joblib"
}
```

---

### 3.2 Stock Summary (`GET /api/stock/{ticker}/summary`)
Fetches price quote, percentage change, and fundamentals. Supports free text (e.g. `sbi stock`, `reliance`, `AAPL`).

**Response `200 OK`:**
```json

  "current_price": 224.23,
  "previous_close": 221.80,
  "change_pct": 1.10,

  "fifty_two_low": 164.08,
  "currency": "USD",
  "last_updated": "2026-08-20T23:00:00.000Z"
```

### 3.3 Periodical Stock Chart (`GET /api/stock/{ticker}/chart?period=1M`)
Returns structured historical time-series OHLCV data formatted for line chart components.

**Query Parameters:**
`period` = `1D`, `1W`, `1M`, `1Y`, `5Y`, `ALL` (default: `1M`)

**Response `200 OK`:**

```json
  "end_price": 224.23,

  "last_updated": "2026-08-20T23:00:00.000Z"
```

### 3.7 Price Alerts REST API

#### Create Alert (`POST /api/alerts`)
```json
{
  "ticker": "AAPL",
  "target_price": 325.00,
  "condition": "above",
  "currency_symbol": "$"
}
```

#### Check & Trigger Active Alerts (`POST /api/alerts/check`)
Evaluates active alerts against live prices. Triggered alerts are marked and returned:
```json
{
  "checked_count": 2,
  "triggered_count": 1,
  "triggered_alerts": [
    {
      "alert_id": "8f3b2...",
      "ticker": "AAPL",
      "target_price": 325.00,
      "current_price": 326.50,
      "condition": "above",
      "currency_symbol": "$",
      "message": "🚨 AAPL has hit $326.50 (Target: above $325.00)!"
    }
  ]
}
```

## 4. Auth JWT Validation Handoff

Host app signs a JWT using `HOST_APP_JWT_SECRET` (HS256):
```json
{
  "sub": "user_12345",
  "exp": 1789800000,
  "iss": "my-host-app"
}
```
Include `Authorization: Bearer <TOKEN>` in HTTP requests. For local development, set `DISABLE_AUTH=true` in `.env` to bypass token verification.

## 5. Mobile Native Push Notifications & JS Bridge

When embedded in mobile applications (React Native, iOS WKWebView, Android WebView, Flutter), the module communicates alert lifecycle events via standard bridge hooks:

### 1. Alert Created Event (`stock-module:alert-created`)
Dispatched when user configures a new alert:
```json
{
  "type": "stock-module:alert-created",
  "payload": {
    "ticker": "SBIN.NS",
    "target_price": 1100.00,
    "condition": "above",
    "currency_symbol": "₹",
    "timestamp": "2026-08-21T01:00:00.000Z"
  }
}
```

### 2. Alert Triggered Event (`stock-module:alert-triggered`)
Dispatched when price crosses the target threshold:
```json
{
  "type": "stock-module:alert-triggered",
  "payload": {
    "title": "⚡ Price Alert Triggered: SBIN.NS",
    "body": "🚨 SBIN.NS has hit ₹1102.50 (Target: above ₹1100.00)!",
    "data": { "ticker": "SBIN.NS", "current_price": 1102.50 }
  }
}
```
The native mobile host app can bind these events to schedule local push notifications via **Apple Push Notification Service (APNs)** or **Firebase Cloud Messaging (FCM)**.
